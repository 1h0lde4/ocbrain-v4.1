## Proposed Changes

### Component 1: Semantic Description Separation (G1)

**Problem**: After the K42-001 fix, `_validate_structured_form()` sets both `description` and `raw_request` to `intent.raw_request`. For single-goal requests they are byte-identical, meaning capability discovery has no semantic signal beyond the raw text.

**Fix**: Add a `semantic_description` field to `Goal.structured_form` that carries the interpreted meaning (hypothesis label + category + raw text), distinct from the preserved `raw_request`. Update capability discovery to use `semantic_description` for matching.

#### [MODIFY] [intent.py](file:///c:/Users/Produ/Downloads/ocbrain-v4.1-main(8)/ocbrain-v4.1-main/core/cognitive/intent.py)

In `_validate_structured_form()` (L741–L745):
- Add `semantic_description` to `structured_form` dict, built from `intent.selected.label` + category + raw text
- Keep `raw_request` unchanged (original user text)
- Keep `description` as the compound-goal-aware text (backward compatible with existing consumers)
- For compound goals, `semantic_description` gets the sub-part text with its semantic context

```diff
 structured_form: Dict[str, Any] = {
     "description": intent.raw_request,
     "category": category,
     "raw_request": intent.raw_request,
+    "semantic_description": (
+        f"{intent.selected.label}: {intent.raw_request}"
+        if intent.selected and intent.selected.label != "novel"
+        else intent.raw_request
+    ),
 }
```

For compound goals (L843–L845), also update semantic_description to reflect the sub-part.

#### [MODIFY] [planner.py](file:///c:/Users/Produ/Downloads/ocbrain-v4.1-main(8)/ocbrain-v4.1-main/core/cognitive/planner.py)

In `build_capability_discovery_request()` (L610) and `_decompose()` (L1111):
- Change description source from `"description"` to `"semantic_description"` with fallback to `"description"`

### Component 3: Intent Ontology Read Path (G3)

**Problem**: `interpret_request()` accepts `known_categories` but no caller ever populates it from memory. The Intent Ontology write path exists (`validation_gate()` with `ContentDomain.INTENT_ONTOLOGY`) but there's no corresponding read path.

**Fix**: Add a `load_known_categories()` function that queries `UnifiedMemory` for promoted Intent Ontology entries. Wire it into the Orchestrator's K4.2 branch.

#### [MODIFY] [intent.py](file:///c:/Users/Produ/Downloads/ocbrain-v4.1-main(8)/ocbrain-v4.1-main/core/cognitive/intent.py)

Add at module level:
```python
async def load_known_categories(
    memory: Optional[UnifiedMemory] = None,
) -> List[str]:
    """Loads promoted Intent Ontology categories from UnifiedMemory.
    
    K4.2 §2: "Intent memory — a promoted L3 knowledge base of
    previously-seen intent categories." Returns an empty list on
    a fresh system where nothing has been promoted yet (the expected,
    correct input to generate_hypotheses' known_categories parameter).
    """
    memory = memory or get_unified_memory()
    try:
        results = await memory.search(
            "intent_ontology", max_results=100,
            filters={"content_type": "intent_ontology"}
        )
        return list({r.content for r in results if r.content})
    except Exception:
        return []
```

#### [MODIFY] [orchestrator.py](file:///c:/Users/Produ/Downloads/ocbrain-v4.1-main(8)/ocbrain-v4.1-main/core/orchestrator.py)

In the K4.2 branch (L287–L288): call `load_known_categories()` and pass it to `interpret_request()`.

### Component 4: User Cognitive Model Wiring (G4)

**Fix**: Wire `assemble_user_cognitive_model()` into the Orchestrator's K4.2 branch, generating `PlannerHint`s from the projection and passing them through `PlannerRequest.hints`.

#### [MODIFY] [orchestrator.py](file:///c:/Users/Produ/Downloads/ocbrain-v4.1-main(8)/ocbrain-v4.1-main/core/orchestrator.py)

```python
from core.cognitive.user_model import assemble_user_cognitive_model
from core.cognitive.planner import PlannerHint, HintSource

projection = await assemble_user_cognitive_model(memory=self.memory)
user_hints = []
if projection.preferred_abstraction_level:
    user_hints.append(PlannerHint(
        kind=f"abstraction_level:{projection.preferred_abstraction_level}",
        weight=0.5,
        source=HintSource.USER_MODEL,
    ))

    user_hints.append(PlannerHint(
        kind=f"communication_style:{projection.communication_style}",
        weight=0.4,
        source=HintSource.USER_MODEL,
    ))

planner_request = PlannerRequest(
    goal_id=goal.resource_id,
    goal=goal,
    hints=user_hints,
)
```
