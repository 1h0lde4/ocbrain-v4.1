## F. Runtime Path Verification

**K4.2 canonical path (use_k42_frontend=true):**
```
Orchestrator.handle(query)
  → load_known_categories(memory)              [G3]
  → interpret_request(query, known_categories) [G1, G2]
  → assemble_user_cognitive_model(memory)      [G4]
  → PlannerRequest(goal, hints=user_hints)     [G4]
  → plan(request, registry)                    [G5, G6]
      → _extract_constraints (uses semantic_description) [G1, G6]
      → _decompose → discover_capabilities    [G1]
      → _detect_impasse → emit event          [G5]
  → compile(execution_plan)
  → WorkflowRuntime.execute(workflow_definition)
  → EvaluatorWorker → ReflectionWorker
  → memory.write + context.save
```

**Error paths verified (no internal leakage):**
- Budget-exhausted impasse → user-safe message ✅
- Precheck rejection → user-safe message ✅
- Compilation rejection → user-safe message + SupervisorWorker ✅
- General exception → user-safe message ✅
